02 / NOTIFICATIONS

알림과 개인정보

무엇이 알림으로 전송되는지, 어떤 내용을 공유할지 확인하고 선택하세요.

응답 종료와 작업 성공기본으로 공유되는 내용내용 없는 일반 알림상세 결과 공유알림이 보이지 않을 때

응답 종료와 작업 성공

완료 hook은 에이전트의 이번 응답이 끝났을 때 알림을 보냅니다. 작업이 성공했는지, 테스트가 통과했는지, 배포까지 했는지는 결과 내용에서 따로 확인해야 합니다.

예를 들어 “테스트 통과, 배포 미수행”은 검증된 작업 범위와 남은 단계를 함께 보여주는 알림입니다. 단순한 응답 종료를 전체 목표 달성으로 해석하지 않습니다.

진행 카드는 에이전트의 단계 업데이트, 오래 걸리는 CLI 감시는 외부 watchdog, 응답 종료는 완료 hook이 각각 맡습니다. Desktop을 열었다고 60초 watchdog이 자동 실행되지는 않습니다.

기본으로 공유되는 내용

완료 미리보기는 현재 완료 이벤트의 요청과 마지막 답변에서 짧은 주제·결과·가능한 검증 정보를 로컬로 추출합니다. 별도 모델 호출 없이 처리하지만, 추출된 미리보기는 ActivitySmith로 전송되며 잠금화면에 표시될 수 있습니다.

전체 대화나 파일을 자동 업로드하지 않습니다. 코드 블록, URL, 이메일, 일부 경로와 명확한 자격 증명 형태 등을 제외하지만 모든 민감 정보를 탐지하는 것은 아닙니다. 문장 안의 개인정보나 기밀이 남을 수 있습니다.

API 키는 macOS Keychain에 저장합니다. 설치 백업과 복구 기록도 개인 설정이므로 공개 저장소에 넣지 마세요.

내용 없는 일반 알림

민감한 작업에서는 완료 알림을 보내는 프로세스의 환경에 아래 값을 설정하세요.

설정값
WATCHSMITH_COMPLETION_PREVIEW=0

이 설정은 자동·대기열 미리보기를 모두 끄고 중립적인 알림 문구를 사용합니다. 키나 알림 연결 자체를 삭제하는 설정은 아닙니다.

터미널에서 실행하는 경우

Codex를 시작할 같은 터미널에서 환경 변수를 지정한 뒤 실행합니다.

터미널 환경 설정
export WATCHSMITH_COMPLETION_PREVIEW=0

Desktop에서 실행하는 경우

터미널에만 설정한 값은 Desktop이 실행하는 알림 프로세스에 전달되지 않을 수 있습니다. 실제로 notifier를 실행하는 환경에 값을 적용하고 해당 클라이언트를 다시 시작해야 합니다. 실행 방식에 맞는 환경 설정과 실제 수신 내용까지 확인하세요.

설정값을 복사한 것만으로 적용되지는 않습니다.

웹페이지는 시스템 설정을 변경하지 않습니다. 실제 알림 프로세스에 값이 전달되는지 확인해야 합니다.

상세 결과 공유

앱 안에서 보는 상세 결과(metadata)는 별도의 선택 사항입니다. 수행 내용·검증·남은 문제를 검토한 짧은 요약으로 준비하고, 사용자의 동의가 있을 때만 전송합니다. 잠금화면 미리보기와 상세 metadata의 공유 동의는 구분합니다.

상세 metadata도 ActivitySmith에 저장되는 정보입니다. 원본 프롬프트·응답·소스코드·로그·개인 문서 등을 그대로 복사하지 않습니다. 로컬 결과 준비 도구는 구조를 검사할 뿐, 비밀 정보 검출이나 공유 동의를 대신하지 않습니다.

알림이 보이지 않을 때

먼저 같은 ActivitySmith 계정에 휴대폰이 연결돼 있는지, iOS 알림과 Live Activities가 허용돼 있는지 확인하세요. 로컬 설치 상태는 watchsmith doctor로 점검할 수 있습니다.

전송 성공은 기기 표시 영수증이 아닙니다. 표시가 없다는 이유만으로 같은 알림을 반복 전송하지 마세요. 카드 종료는 잠금화면 제거 요청이며 ActivitySmith 앱 내부 기록 삭제와는 다릅니다.
