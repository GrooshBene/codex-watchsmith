01 / GET STARTED

설치와 연결

Mac에서 설치하고 iPhone에서 확인하기까지. 필요한 준비와 두 가지 연결을 차례로 안내합니다.

시작 전 준비설치 마법사 실행두 연결의 차이실제 알림 확인나중에 설정 이어가기

시작 전 준비

Watchsmith는 Mac의 Codex 작업을 ActivitySmith 계정에 연결합니다. 계정 생성과 휴대폰 연결은 먼저 준비해 주세요.

  • Mac: macOS, zsh, Python 3.11 이상이 python3로 실행돼야 합니다.
  • Codex: 로그인한 Desktop 또는 CLI가 필요합니다. Desktop만 사용한다면 Codex CLI는 필수가 아닙니다.
  • ActivitySmith: 계정에 iOS 앱을 연결하고 알림과 Live Activities를 허용합니다.
  • Node.js/npm: ActivitySmith CLI 설치에 사용합니다. npm이 있으면 마법사가 CLI 설치를 안내합니다.

ActivitySmith에서 계정·기기 연결하기 ↗

설치 마법사 실행

공식 안정 릴리스 패키지를 다운로드하고 압축을 푸세요. 진행 중인 작업을 마치고 영향을 받는 클라이언트를 닫은 뒤, 압축을 푼 폴더의 터미널에서 실행합니다.

설치 마법사
./setup.sh

마법사는 환경과 기존 설치를 확인하고 변경 내용을 적용하기 전에 묻습니다. 기존 알림 연결과 설정을 보존하며, 필요한 API 키는 macOS Keychain에 저장합니다. 명령 경로 추가와 테스트 Push는 선택할 수 있습니다.

기본 설치 위치는 ~/.codex입니다. 사용자 지정 CODEX_HOME을 쓰는 경우 설치 전 지정하고 이후에도 같은 위치를 사용하세요. Python이나 npm이 없으면 해당 도구를 준비한 뒤 다시 실행합니다.

설치 마법사는 터미널에서 실행하세요.

대화형 입력이 필요합니다. 웹페이지의 복사 버튼은 명령만 복사하며 설치하거나 알림을 보내지 않습니다.

두 연결의 차이

연결용도준비할 것
ActivitySmith MCP에이전트가 의미 있는 진행 상황을 Live Activity로 표시Codex에서 별도 MCP 연결과 인증
ActivitySmith CLI / API 키응답 종료 Push, 래퍼로 실행한 CLI 작업 감시휴대폰과 같은 계정의 API 키, macOS Keychain 등록

MCP 인증과 API 키는 별개입니다. MCP 없이도 완료 Push와 CLI 감시는 사용할 수 있습니다. 설정에 MCP 항목이 있다는 사실만으로 인증 성공이 확인되는 것은 아닙니다.

ActivitySmith의 MCP 연결 절차 ↗

실제 알림 확인

  1. Codex를 다시 시작하고 새 터미널을 엽니다.
  2. 아래 진단으로 설치 상태를 확인합니다.
  3. 작은 Codex 작업을 완료하고 휴대폰에서 완료 Push를 확인합니다.
설치 진단
watchsmith doctor

진단은 로컬 설정과 설치 파일 등을 읽기 전용으로 확인합니다. 테스트 알림을 보내거나 MCP 인증·기기 표시까지 검증하지 않습니다. 마법사에서 Push 테스트를 건너뛰었다면 activitysmith-test로 시험할 수 있습니다. 이 명령은 실제 테스트 알림을 전송합니다.

전송 수락과 기기 수신은 다릅니다.

서버가 전송을 수락해도 표시가 지연되거나 누락될 수 있습니다. 최종 확인은 휴대폰에서 알림이 보이는지 확인하는 것입니다.

나중에 설정 이어가기

설정 이어가기
watchsmith setup

이미 설치했다면 연결이나 명령 경로 설정을 나중에 이어갈 수 있습니다. 설치된 파일을 복구하거나 버전을 바꾸려면 업데이트·복구 안내를 확인하세요.
